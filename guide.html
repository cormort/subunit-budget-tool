V39.0 操作說明與測試資料

先使用 test-data 內的檔案完成自我測試，再匯入正式資料。所有處理均在瀏覽器本機完成。

1. 基金資料庫

  1. 開啟「基金資料庫」主分頁。
  2. 匯入 08_基金資料庫_測試資料.json。
  3. 左側應顯示 2 筆、1 個年度、2 種屬性。
  4. 切換到階層式查詢，搜尋「關鍵字」，應找到測試政事基金。
  5. 測試 JSON 與 Excel 匯出。

2. 收支數字提取與彙總

  1. 選「作業基金」，匯入 01、02 與 04。
  2. 正常資料應辨識業務收入 120,000,000 元；短絀資料應顯示負 10,000,000 元。
  3. 缺漏資料應在品質檢查顯示「未識別」。
  4. 再次匯入相同檔案，匯入紀錄應顯示「略過重複」。
  5. 刪除一筆後，合計應立即重算。
  6. 切換「政事基金」，匯入 03，再測試 Excel 與 JSON 匯出。

文件文字與正式格式差異很大時，請以品質檢查結果為準，不要直接採用低分資料。

3. 作業基金分析說明產生器

  1. 一次匯入 05、06、07。
  2. 三個狀態框應分別識別正確類型，其中 05 為 2 頁 PDF。
  3. 輸入基金名稱與年度，按「產生完整分析說明」。
  4. 檢查分析說明、三張解析表及「勾稽及待補項目」。
  5. 測試複製純文字、TXT、HTML 與解析 Excel。
  6. 測試個別移除及全部重設。

4. GitHub Pages 與離線檢查

  • 部署後確認 assets/vendor 的 4 個 JS 都回傳 HTTP 200。
  • 本機離線測試請執行 python -m http.server 8000，不要只雙擊 HTML。
  • 完整部署檢查請開啟專案內 GITHUB_PAGES_CHECKLIST.md。

已知限制

  • 掃描型 PDF 必須先 OCR。
  • PDF 表格若沒有明確欄位間距，仍可能需要人工核對。
  • DOCX 財務文字若使用不同科目名稱，可能顯示「未識別」。
  • 產生的分析說明為核對草稿，紅色待補內容仍須人工修正。
